Know the exact height. Live, in your viewport.

Live Dimension: Height is an Unreal Engine editor plugin that shows the height of an object right in the viewport. The measurement updates live when the object is moved, rotated, or scaled, so you can check proportions without leaving the editor. It is designed for environment artists, level designers, and architectural visualization workflows.

Frequently asked questions

What does Live Dimension: Height do?

It displays the height of an object in the Unreal Engine viewport and keeps the value updated as you move, rotate, or scale the object.

Which Unreal Engine versions are supported?

Unreal Engine versions above 5.0 are supported.

About

About OP PLUGINS

OP PLUGINS develops tools and software intended to improve creative and technical workflows. Our current focus is plugins for Unreal Engine, aimed at environment artists, technical artists, level designers, game developers, and studios.

What we build

We build practical tools that live inside the editor and remove repetitive or error-prone steps, such as measuring objects in the viewport or setting up character rigs.

How we work

We label each product's status plainly, we publish supported versions only after we have verified them, and we keep this site free of third-party trackers.
